# COMP1786 — Eventa

Nhánh **CW** chứa hai ứng dụng coursework:

- [cw-admin](cw-admin/README.md): Admin Android native Java, giao diện sáng/hồng; A–D và chủ đề/ảnh tùy chọn.
- [cw-user](cw-user/README.md): Explore Dart/Flutter, giao diện xanh/trắng; G/H hiện đọc snapshot.
- [cloud/firebase](cloud/firebase/README.md): cấu hình Firebase Spark Android/web. Firestore đóng quyền client; upload/đồng bộ E và đọc Cloud G chưa triển khai.
- [logbook](logbook/README.md): bài thực hành Java/XML Views.

Mở cw-admin bằng Android Studio cho Admin; mở cw-user/app cho Flutter. Xem README từng thư mục để build và kiểm tra.
